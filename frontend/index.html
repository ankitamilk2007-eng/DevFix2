Privacy & Data Governance

Transparent handling of your code and debugging sessions

📂 Local Storage

Debugging sessions, drafts, and UI preferences are stored directly in your browser's localStorage. No telemetry or tracking scripts are loaded.

🛡 Explicit Submission Only

Source code and tracebacks are never sent to any server in the background. Network requests are only dispatched when you explicitly click "Analyze Error" or "Verify".

🔒 Controlled Verification

Code verification runs in isolated environments with resource limits, restricted filesystem access, and strict timeouts to prevent accidental side effects.
